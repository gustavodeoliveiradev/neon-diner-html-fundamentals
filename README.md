# 🍔 Neon Diner 2077 — Cyberpunk Menu

Um projeto desenvolvido para praticar **listas de definição** e **agrupamento semântico de dados** em HTML5 puro, sem estilização CSS.

O projeto simula o cardápio de uma cantina futurista em Neo-Metrópole, destacando opções de refeições sintéticas, bebidas energéticas e combos promocionais.

---

## 🚀 Tecnologias e Conceitos Aplicados

Neste projeto, explorei as seguintes tags e estruturas do HTML5:

* **Listas de Definição:** `<dl>`, `<dt>` e `<dd>` para associar nomes de pratos às suas descrições e preços de forma semântica.
* **Agrupamento por Seções:** `<section>` para organizar categorias de produtos (*Food*, *Drinks* e *Combos*).
* **Tabelas de Preços:** `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>` para a exibição de pacotes promocionais.
* **Estrutura de Layout:** `<header>`, `<main>`, `<footer`> e `<hr>`.
* **Formatação de Texto:** `<strong>`, `<em>` e `<small>`.
